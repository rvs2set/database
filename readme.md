Выбранная предметная область: Учет товарных позиций (каталог товаров с полями ID, название, цена, количество).

Описание программной рализации:

•	Интерфейс пользователя спроектирован с помощью визуального редактора Qt Designer (mainwindow.ui), содержит таблицы (QTableView), поля ввода (QLineEdit) и кнопки управления (QPushButton).

•	Класс DatabaseManager выполняет всю работу с бинарными потоками std::fstream, обеспечивая создание, открытие, запись, поиск и резервное копирование данных.

Описание реализованного функционала
•	Создание, открытие и очистка БД: Методы createDatabase и openDatabase инициализируют бинарные потоки файлов данных и индексов. Очистка базы данных полностью стирает содержимое файлов и сбрасывает индексы в начальное состояние.

•	Добавление записи с проверкой уникальности: Перед добавлением новой записи система проверяет уникальность ключа id по индексному файлу. Успешная запись дописывается в конец файла (std::ios::app), после чего индекс обновляется.

•	Удаление записей (по ключевому и неключевому полю):
1.	По уникальному ключу (id) поиск и удаление выполняются мгновенно через индексное смещение.
2.	По неключевому полю (например, name) выполняется линейный обход активных записей, при котором удаляются все элементы, совпадающие по значению.
   
•	Поиск записей:
1.	Поиск по ID возвращает конкретную запись за логарифмическое время O(log N) благодаря индексации.
2.	Поиск по наименованию возвращает список всех подходящих записей (std::vector<Record>), которые динамически выводятся в таблице интерфейса.
   
•	Редактирование записи: Поиск записи по id определяет ее точное байтовое смещение в файле (file_offset), после чего старые данные перезаписываются новыми значениями.

•	Резервное копирование и восстановление (Backup / Restore): Функции бэкапа побайтово копируют рабочие файлы базы данных в архивную директорию, а функция восстановления возвращает их обратно в рабочую область.

•	Экспорт в сторонний формат (*.xlsx / CSV): Считывание всех актуальных записей из бинарной базы и генерация табличного файла для просмотра в Microsoft Excel или LibreOffice.
